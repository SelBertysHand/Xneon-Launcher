# Xneon Reborn — быстрый старт (Windows)

Это инструкция для сборки Xneon Reborn из ветки `xneon-reborn`.

## 1. Скачать приложение

1. Откройте [Windows Package в GitHub Actions](https://github.com/SelBertysHand/Xneon-Launcher/actions/workflows/package-windows.yml?query=branch%3Axneon-reborn).
2. Выберите последний запуск со статусом **Success**.
3. Внизу страницы откройте раздел **Artifacts** и скачайте `Xneon-Reborn-Windows`.
4. Распакуйте ZIP артефакта. Внутри находятся установщик Windows (NSIS) и portable ZIP.
5. Для обычной установки запустите установщик. Для portable-варианта распакуйте отдельный ZIP в постоянную папку и запустите `Xneon Launcher.exe`.

Не запускайте одновременно установленную и portable-копии с одним и тем же профилем данных.

## 2. Первый запуск и аккаунт

- Для официальных серверов и лицензированного Minecraft используйте вход Microsoft и аккаунт, которому принадлежит Minecraft Java Edition.
- Offline-аккаунт подходит для локальной игры и серверов, разрешающих offline-mode. Он не заменяет лицензию и не даёт вход на официальные online-mode серверы.
- Не передавайте никому файлы профиля, токены, пароли и содержимое папки данных лаунчера.

## 3. Создать сборку и запустить игру

1. Откройте раздел сборок и создайте новую сборку.
2. Выберите версию Minecraft. Для первой проверки удобнее Vanilla 1.20.1.
3. Если нужны моды, выберите один загрузчик — Fabric, Forge, NeoForge или Quilt — и совместимые с ним моды той же версии Minecraft.
4. Откройте настройки сборки и оставьте автоматический выбор Java, если нет особой причины указывать свою.
5. Выберите аккаунт, нажмите «Запустить» и дождитесь загрузки библиотек, ресурсов и Java.
6. При первом запуске загрузка может занять заметное время; не закрывайте лаунчер до появления игрового окна.

## 4. Миры и резервные копии

Во вкладке миров можно создавать ручные копии и восстанавливать сохранения. В «Архиве резервных копий» доступны копии и от уже удалённых миров. Восстановление создаёт отдельную папку мира, не перезаписывая существующую.

Перед ручным удалением или переносом папок сохранений закройте Minecraft. Не удаляйте резервные копии, пока не проверили восстановленный мир.

## 5. Если Minecraft не запускается

1. Откройте логи последнего запуска и найдите раздел диагностики.
2. Проверьте, что версия модов соответствует версии Minecraft и загрузчику.
3. Для проверки запустите чистую Vanilla-сборку без модов.
4. Не публикуйте полный лог без проверки: в нём могут быть локальные пути и данные аккаунта. Лаунчер пытается скрывать чувствительные значения, но перед отправкой всё равно просмотрите файл.

Папка данных Windows по умолчанию: `%APPDATA%\xneonlauncher`. Сохранения конкретной сборки находятся в её каталоге `saves`.

## Что означает статус проверки

- Успешная CI-сборка подтверждает компиляцию, типы и автоматические тесты.
- Windows smoke test подтверждает тихую установку, наличие исполняемого файла и запуск процесса приложения.
- Отдельный Minecraft smoke test проверяет реальный запуск Vanilla-клиента с временным offline-профилем на Windows runner. Это не проверка Microsoft-авторизации или всех модпаков.

## Автообновления

В репозитории уже настроен workflow публикации релизов по тегам `v*`. Для выпуска новой версии нужно увеличить `version` в `package.json`, создать соответствующий тег `vX.Y.Z` и отправить его в GitHub. Workflow соберёт Windows, Linux и macOS варианты и опубликует файлы в GitHub Releases. Для работы обновлений версия в теге должна совпадать с версией в `package.json`.
